# Kino-kod bot

Telegram-бот: пользователь вводит 3-значный код — бот присылает название фильма
и картинку. Интерфейс для пользователей — на узбекском, команды для разработчика —
на русском. Стек: **aiogram 3 + SQLite (aiosqlite)**, деплой на **Railway**.

## Возможности

- `/start` — если кодов ещё нет в базе, бот отвечает фиксированным сообщением
  «пока нет рекламодателей» с контактом `@lixiauto`. Если коды есть — просит
  прислать код.
- Пользователь присылает 3 цифры → бот ищет код и отправляет фото + название
  фильма, либо сообщение «не найдено».
- Обязательная подписка на каналы: пока пользователь не подписан на все каналы
  из списка админа, бот показывает инлайн-кнопки с каналами и кнопку
  «✅ Tekshirish» для повторной проверки.
- Под карточкой фильма — кнопка «🍿 KO'RISH 🎬». По нажатию бот присылает
  сам файл фильма (видео/документ), который админ прикрепил при добавлении кода.

## Команды администратора (для разработчика)

`/addcode` — пошаговый мастер добавления фильма:

1. `/addcode` (можно сразу с кодом и названием: `/addcode 123 Название фильма`,
   тогда шаги 2–3 пропускаются)
2. бот просит код (3 цифры)
3. бот просит название фильма
4. бот просит фото-обложку для карточки
5. бот просит видео/файл — сам фильм, который уйдёт пользователю по кнопке
   «🍿 KO'RISH 🎬»

На любом шаге можно отправить `/cancel`, чтобы прервать добавление.

Остальные команды:

| Команда | Формат | Описание |
|---|---|---|
| `/delcode` | `/delcode 123` | удалить код |
| `/stats` | `/stats` | статистика: коды, каналы, пользователи, поиски, топ кодов |
| `/addch` | `/addch @username` или `/addch -100xxxxxxxxxx https://t.me/+invite` | добавить обязательный канал |
| `/delch` | `/delch @username` или `/delch -100xxxxxxxxxx` | удалить канал |
| `/ch` | `/ch` | список каналов |

Эти команды видны и работают только для ID из `ADMIN_IDS` — у остальных
пользователей бот просто не отвечает на них.

**Про размер видео:** обычный Bot API позволяет боту принимать файлы до
~20 МБ и отправлять — до ~50 МБ. Для более крупных фильмов потребуется свой
локальный Bot API сервер (Local Bot API Server) — если фильмы будут большими,
дайте знать, помогу с этим отдельно.

**Важно про `/addch`:** для приватных каналов, у которых нет `@username`,
бот не сможет получить данные о канале, если он не добавлен в этот канал
администратором. Добавьте бота в канал как админа перед вызовом `/addch`.
Проверка подписки (`get_chat_member`) тоже требует, чтобы бот состоял
в канале.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

```
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789,987654321   # ваш Telegram user id и id других разработчиков
DB_PATH=bot.db                  # путь к файлу SQLite
```

Свой Telegram user id можно узнать, например, у `@userinfobot`.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # и заполнить значения
python bot.py
```

## Деплой на Railway

1. Залейте проект в GitHub-репозиторий (или используйте `railway up` через
   Railway CLI прямо из этой папки).
2. В Railway создайте новый проект → Deploy from GitHub repo, выберите
   репозиторий.
3. Railway сам определит Python-проект и `Procfile`/`railway.json` и запустит
   `python bot.py` как worker.
4. В настройках проекта → **Variables** добавьте `BOT_TOKEN` и `ADMIN_IDS`
   (и при необходимости `DB_PATH`).
5. **Про хранение данных:** по умолчанию файловая система Railway
   эфемерна — при новом деплое файл `bot.db` обнулится. Чтобы коды и каналы
   сохранялись между деплоями, подключите **Volume** (Settings → Volumes),
   примонтируйте его, например, на `/data`, и укажите
   `DB_PATH=/data/bot.db` в переменных окружения.

## Если бот уже был запущен раньше

База обновится автоматически (добавятся нужные поля) — старые коды продолжат
работать для показа карточки. Кнопка «🍿 KO'RISH 🎬» у них покажет «Bu film
hali yuklanmagan» (видео ещё не загружено), пока вы не пересохраните код через
`/addcode` заново, приложив видео.

## Структура проекта

```
kino-bot/
├── bot.py              # точка входа, роутеры, polling
├── config.py           # переменные окружения, admin id, тексты
├── database.py         # SQLite: коды, каналы, пользователи, статистика
├── keyboards.py         # инлайн-клавиатуры (подписка)
├── handlers/
│   ├── user.py          # /start, проверка подписки, поиск по коду (узб.)
│   └── admin.py         # /addcode /delcode /stats /addch /delch /ch (рус.)
├── requirements.txt
├── Procfile
├── railway.json
└── .env.example
```
